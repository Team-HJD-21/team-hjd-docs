# 에디터 도구

> **중요도: 중요** · Unity에서 게임을 실행하고 상태·문제·실험 결과를 확인할 때 읽습니다.

프로젝트 API가 Feature를 **코드로 연결하는 방법**이라면, 에디터 도구는 연결된 게임을 **관측하고 시험하는 방법**입니다. 프로젝트별 도구의 진입점, 조작 방법, 수치의 의미와 안전한 사용 범위를 정리합니다.

## 프로젝트 선택

| 프로젝트 | 도구 | 할 수 있는 일 |
| --- | --- | --- |
| [The Developer](the-developer/index.md) | [Game Debugger](the-developer/game-debugger/index.md) | Match 모니터링, 배속·정지, Grid·전선 조회, 스폰 요청·판단 검사, 시간 통계와 기록 공유 |

다른 프로젝트의 도구가 준비되면 별도 카테고리로 추가합니다. The Developer의 Match·스폰 정책을 모든 프로젝트의 공통 규칙으로 취급하지 않습니다.

## 문서 선택 기준

- 직접 조작하며 시험하려면 이 **에디터 도구** 문서를 읽습니다.
- 타입·메서드·이벤트를 연동하려면 [프로젝트 API](../projects/index.md)를 읽습니다.
- Git·PR·팀 운영 방식은 [협업 가이드](../collaboration/overview.md)를 읽습니다.
