# 터렛 검증과 제한 사항

**기준:** 게임 main `1a03e9a9164e5db94cbc8775162467d08cf63a3b` (2026-11-05), 공개 API·현재 구현 정적 대조.

| 시나리오 | 확인할 결과 |
| --- | --- |
| 정상 초기화 후 켜기 | `Activated`; 전력은 한 번만 예약 |
| 켜진 터렛에 다시 켜기 | `Unchanged`; 전력 중복 차감 없음 |
| 켜진 터렛 끄기 | `Deactivated`; 예약 해제 |
| 활성 과열 | `IsActivated`와 예약 전력 유지, `IsOperational == false`, 냉각 남은 시간 표시 |
| 냉각 중 OFF 후 다시 켜기 | 냉각 종료까지 `CoolingDown`; 종료 후 자동 활성화 없이 ON 가능 |
| 전력 부족 | `InsufficientPower`; 켜졌다고 표시하지 않음 |
| 잠긴 / 파괴된 터렛 켜기 | `Locked` / `Destroyed` |
| 초기화 전 요청 | 공급자 없이 성공으로 취급하지 않음 |
| 피해로 체력 0 | 파괴·비활성화·예약 부분 반환 및 잔여 예약·UI 갱신 |
| 복구 | 체력·파괴 상태 복구; 켜기 요청은 별도 |
| 등록 해제 후 이벤트 | 스냅샷 false → UI와 타깃 제거 |
| 레벨 교체 | 결과 enum 확인, 교체 후 컴포넌트 재조회 |
| 활성·냉각·자동 활성화 중 강화/레벨 변경 | 각각 제한 결과를 반환하고 객체·단계·전력은 변경하지 않음 |
| 씬 왕복 | 정적 이벤트 구독 누수·예전 ID 오사용 없음 |
| Transform 이동 | 이벤트만 의존하지 않고 위치 입력 갱신 |

## 부분 수리 확인 — main 6b4310dc

- Repair가 최대 체력에서 멈추고 실제 변경 때만 true와 체력·Snapshot 알림을 내는지 확인합니다.
- 활성·냉각 중 수리가 활성 상태·전력 예약·냉각을 바꾸지 않는지 확인합니다.
- 초기화 전·비활성·잠금·파괴·자동 활성화 중·만피·양수가 아닌 회복량을 거부하는지 확인합니다.
- 스패너의 같은 씬·거리·전방·가림·타격 시 재검사와 CU·임시 터렛 제외를 확인합니다.

#549의 공개 API 실행 체크리스트이며 이번 문서 작업에서 Unity 플레이를 수행한 기록이 아닙니다.

## 현재 제한

- 활성화 상태와 operational 상태가 다릅니다. 적의 `DamageableTargetAdapter`는 현재 활성 상태를 기준으로 하므로 일시 중지한 터렛도 타깃이 될 수 있습니다.
- Cannon/Missile 계열의 공통 `FieldTurretBase` 연동과 기존 Laser 구현을 같은 API로 완전히 통합했다고 가정하지 않습니다.
- 스냅샷은 읽기 계약이며 서버 권한, RPC, 저장/로드를 자동 제공하지 않습니다.
- 프리팹 정의·전력 공급·씬 초기화 참조는 소비자가 해당 씬에서 확인해야 합니다.
- 미병합 기능은 main 가이드에 포함하지 않습니다. 개발 브랜치 변경은 병합 후 별도 검토하여 이 문서를 업데이트합니다.

관련: [전체 통합 체크리스트](../integration.md) · [공통 품질 확인](../../../delivery/quality-checks.md)


## 파괴 반환·우선순위·수리 배치 — main 1a03e9a9

- 파괴 비율 0/25/50/100%, 홀수 예약 내림, 잘못된 설정 거부, 이미 파괴된 대상 재정산 금지와 Restore 잔여 반환을 확인합니다.
- 상위 후보가 냉각/반환을 기다릴 때 하위 후보를 먼저 켜지 않는지, 영구 전력 부족 후보만 제외하는지 확인합니다.
- Initial_Stage의 FieldTurret Repair Tests 그룹에는 OFF 상태 Canon LV1 두 개가 있습니다. Destroyed는 HP 0/100으로 일반 Repair 거부·Restore 후 최대 HP/OFF, Damaged는 HP 50/100으로 일반 수리 상한을 확인합니다.
- 테스트 그룹 재활성화가 수리/복구 결과를 초기화하지 않는지와 논리 ID·컨트롤러 소속을 확인합니다.

이 배치와 원본이 보고한 Unity 검사 이력은 Player 실제 키 유지·거리 이탈·수리 모션·다중 Client 검증과 별도입니다. 이번 사이트 동기화는 원본 시험을 재실행하지 않았습니다.
