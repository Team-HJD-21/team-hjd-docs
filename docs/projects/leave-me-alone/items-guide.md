# 아이템 사용 안내

:::info 확인 범위
원본 `main` 커밋 `03e20da0eeef6350f2a26807811d81c55bea74dd`의 Docs에 기록된 현재 코드 효과를 요약했습니다. 실제 밸런스나 플레이 감각을 확인한 결과는 아닙니다.
:::

아이템은 작물 수확으로 얻을 수 있습니다. 아이콘이 켜졌을 때 해당 키를 누르면 아이템이 자동으로 작동합니다.

| 아이템 | 입력 | 확인한 효과 | 참고 |
| --- | --- | --- | --- |
| Pickup Truck | `1` | 자동으로 이동해 상대 밭의 작물 진행 상태를 되돌립니다. | 상대 차량 아이템이 사용 중이면 생성이 제한될 수 있습니다. |
| Boost Drone | `2` | 소유자 농장의 성장 간격과 익는 대기시간을 줄입니다. | 성장 간격은 2초에서 1초로, 익는 시간은 10초에서 5초로 바뀌며 60초 뒤 기본값 복구가 예약됩니다. |
| Toxic Drone | `3` | 작물을 초기 상태로 되돌리는 효과가 있습니다. | 확인한 코드 설명에서는 각 소유자 자신의 작물 목록을 대상으로 하므로, 상대 밭을 공격할 것이라는 제품 설명과 다를 수 있습니다. |

드론은 Boost와 Toxic 중 하나를 선택해 사용하며, 사용하면 드론 보유 상태를 소비합니다. 차량과 드론은 별도 조준 없이 자동으로 동작합니다.

아이템 대상이나 효과가 코드·기획 변경으로 달라지면 현재 `main` 구현과 승인된 제품 동작을 각각 확인한 뒤 이 페이지를 갱신하세요.
