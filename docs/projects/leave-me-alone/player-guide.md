# 플레이어 가이드

:::info 확인 범위
원본 `main` 커밋 `03e20da0eeef6350f2a26807811d81c55bea74dd`의 문서와 입력·작물 규칙 요약을 기준으로 작성했습니다. 실제 플레이 테스트 결과는 아닙니다.
:::

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| `Left Shift` | 달리기 |
| 마우스 이동 | 시점 회전 |
| 마우스 왼쪽 버튼 | 조준한 작물과 상호작용. 작업 중에는 누른 상태를 유지합니다. |
| `Tab` | 안내 창 열기/닫기. 안내 창을 열면 경기 시간이 멈춥니다. |
| `1` | Pickup Truck 사용 |
| `2` | Boost Drone 사용 |
| `3` | Toxic Drone 사용 |

작물에 가까이 다가가 화면 중앙으로 조준한 뒤 상호작용합니다. 작물 작업 중 이동은 제한될 수 있으며, 버튼을 놓거나 다른 대상을 조준하면 작업이 취소되거나 물주기가 중단될 수 있습니다.

## 내 밭 관리

빈 밭을 조준하고 왼쪽 버튼을 약 4초간 누르면 씨앗을 심습니다. 작물을 조준한 채 버튼을 유지하면 물을 줄 수 있습니다. 물주기 작업은 약 10초가 걸리며, 중간에 버튼을 놓으면 작업이 취소될 수 있습니다.

작물은 물을 주는 동안 기본 2초 간격으로 성장합니다. 마지막 성장 단계 이후 기본 10초가 지나면 수확할 수 있습니다. 익은 내 작물을 약 4초간 상호작용하면 수확하며 6점을 얻습니다.

## 상대 밭과 점수

상대 밭에서는 코드 기준으로 익은 작물을 수확할 수 있습니다. 약 4초간 상호작용하면 4점을 얻습니다. 상대 밭에 씨앗을 심거나 물을 줄 수는 없습니다. AI가 작업 중인 작물은 수확할 수 없습니다.

경기는 300초이며, 시간이 끝나면 Player와 AI 점수를 비교해 결과 씬을 선택합니다. 수확과 아이템 보상 세부 사항은 [아이템 사용 안내](items-guide.md)를 참고하세요.
