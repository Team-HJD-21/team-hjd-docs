# Game Debugger 문서 · 로컬 검증 기록

2026-10-08 · 사용자 제공 사진 6장과 영상 6개를 사용했다. #4·#11 사진 자리만 제거하고 해당 기능 설명은 유지했다.

## 자동 검사

- `npm run check`: 기존 프로젝트 API/검색과 도구 문서 11페이지, nav 순서·목차·로컬 링크, 12개 미디어 연결/존재/파일 signature 검사 통과.
- `npm run build`: 정적 배포 빌드 성공. 미리보기 서버가 영상 파일을 읽는 중 재빌드에서 Windows ENOTEMPTY가 한 번 발생하여 서버 종료 후 재빌드에 성공했다.
- 원본/복사본 12개 SHA-256 일치. 재인코딩이나 원본 편집 없음.
- localhost에서 12개 파일 모두 Range `bytes=0-63`에 HTTP 206과 올바른 `image/png` 또는 `video/mp4` 응답.

## 실제 브라우저

- Codex In-app Browser에서 문서 이미지 로딩, 아래 6개 영상의 디코딩/재생을 확인했다.
- 대표 시간 제어 영상의 탐색과 native 전체화면 진입/복귀를 확인했다. 모든 영상에서 각각 전체화면 조작을 반복한 검사는 아니다.
- 1440px 데스크톱 폭: 기존 nav의 프로젝트 API → 에디터 도구 → 용어 사전, 도구 sidebar와 우측 목차, 라이트/다크 스타일 확인.
- 기본 852px 폭과 390px 모바일 폭: 본문/미디어 카드에서 페이지 가로 넘침 없음. 표는 자체 가로 scroll 유지.
- 확인한 페이지의 browser warning/error 로그 없음.

## 사진/영상이 증명하지 않는 것

- #2는 Edit Mode PREVIEW이다. SERVER Play Mode 사진으로 표기하지 않았다.
- #6은 Edit Mode Grid 기본값 변경 영상이다. 실제 Runtime override 적용 장면이 있다고 표기하지 않았으며 사용 방법은 본문에 유지했다.
- #12는 Encounter 요청 합계 표이며 개별 객체/Network ID 목록이 아니다. Encounter로 배치하고 상세 목록 사용법에 링크했다.
- #13은 조건 미선택 상태의 Timeline UI이며 실제 조건부 Pause/선택 사건 상세 화면이 아니다.
- #14는 PARTIAL / Build 미기록인 Capture UI이며 파일 Export 성공 증거가 아니다.
- 문서/미디어 검증은 게임의 전투·밸런스·승패 전체 검증을 의미하지 않는다.

## 배포

사용자 승인 후 문서 저장소 main push로 기존 GitHub Pages workflow를 실행한다. workflow 성공 및 공개 주소의 페이지/미디어 응답은 별도로 확인한다. 게임 저장소의 코드·Scene·PR는 이 배포에서 변경하지 않는다.
